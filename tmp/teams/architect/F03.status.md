# F03 — profiler contract (conditional)

## Status
- **Stage:** build (Slice 1 complete) → intake (pending F03 dogfood decisions)
- **Owner:** unassigned
- **Blocker:** human decisions on attribution, telemetry source, probe validation, and tool-call semantics (see [F03-dogfood-decisions.md](F03-dogfood-decisions.md))

## Goal
Define a harness-agnostic profiler adapter interface with graceful degradation. Each adapter probes its environment (OTel → hooks → local session data → server API → unknown) and reports capabilities. The comparison engine reads capabilities and marks unavailable metrics `unknown` — never inventing them.

## Slice plan
See [F03-slices.md](F03-slices.md) for the full verifiable-unit decomposition.

- **Slice 1:** Adapter interface + Claude Code adapter + profile serialization (critical path; completed 2026-09-10)
- **Slice 1.1:** Claude Code OTel probe validation and tool-call semantics (new; pending decisions)
- **Slice 1.2:** Claude Code session_data (JSONL transcript) adapter (new; pending decisions)
- **Slice 1.3:** Claude Code skill attribution / session boundary (proposed, conditional on the attribution decision)
- **Slice 2:** Cursor adapter (OTel + SQLite fallback) — parallel after Slice 1
- **Slice 3:** Codex adapter (OTel logs + hooks) — parallel after Slice 1
- **Slice 4:** Devin adapter (ATIF + server API) — parallel after Slice 1

F04 can start after Slice 1 only (single-harness comparison). The 1.x slices are hardening, not blockers.
