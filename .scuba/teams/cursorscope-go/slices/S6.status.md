## Goal
Read `cursor.api.request.{input,output,cache_read,cache_creation}_tokens` per request and scope a capture by `cursor.conversation.id`, instead of throwing those fields away and summing a session-blind aggregate metric.

## Definition of done
Given an export containing two conversations, `capture --session <conversation_id>` returns tokens for **only** that conversation; absent per-request events, it falls back to the aggregate `cursor.token.usage` metric and says so in `Source`.
