# S1a — Hook entrypoint: stdin JSON → JSONL spool

- **Stage:** ready — dispatchable now
- **Owner:** unassigned
- **Branch:** none (target: `epic/skill-scope`)
- **Depends on:** none
- **Blocks:** S1b, S2, S4, S11 · **and every slice that adds a bash test** (DoD 7's CI glob — SP1, S2, S8a, S8b)

## Goal
One static Go binary reads a Cursor hook payload on stdin and appends a normalized line to a JSONL spool. No daemon, no port, no long-lived state (Fork i). This is the write half of the old S1, split at the spec gate because the original claimed 13 requirements and its DoD proved about three.

**Widened at round 3** by the source-supply sweep: the spool line is the interface every downstream slice reads, and round 2 pinned only the ten base fields. DoD 6 now pins the whole envelope. **Widened once more at round 4** by DoD 7 — the CI wiring every later bash test depends on (V4-#7).

## Definition of done
1. For **each of the 21** documented hook events (**Specification**, ledger §A5.1:**117-137** — 21 table rows; the header is at :115 and the separator at :116, which round 3 counted as rows, C4-#6), a payload on stdin appends exactly **one** normalized JSONL line carrying **whichever of the 10 documented base fields that event actually supplies**. The ten are `conversation_id`, `generation_id`, `model`, `model_id` (opt), `model_params` (opt), `hook_event_name`, `cursor_version`, `workspace_roots`, `user_email`, `transcript_path` (ledger §A5.1:113). **`workspaceOpen` supplies only four** — `hook_event_name`, `cursor_version`, `workspace_roots`, `user_email` — omitting `conversation_id`, `generation_id`, `model`, `model_id` and `transcript_path` (ledger §A5.1:137). Round 1 asserted a flat "eight base fields on all 21 events", which is false in two directions: the documented set is ten, and one event carries four. Absent fields are written empty, **never invented** (R-SA-02).
2. Malformed JSON, an unwritable spool path, and an unrecognized `hook_event_name` each exit **0** with empty stdout — a hook must never break the Cursor session (R-CS-03).
3. **Bounded memory (R-CS-30's other half).** stdin is consumed through a bounded reader with a documented cap, so payload size cannot grow the process: a **10 MB** payload on stdin still exits 0, writes exactly one line no larger than the cap, and does not buffer the whole input. Round 1 asserted "bounded memory" in the register and proved it nowhere.
4. Spool path resolves from a flag or an environment variable. **No dotenv** — a Design decision, not a repo rule: `AGENTS.md` (23 lines) says nothing about env files.
5. Single static Go build; `profiler/go.mod` still declares zero `require`s (R-CS-28 — the port's actual justification over Node ≥20 + `npm install`).
6. **The spool line contract is pinned here — every non-base field a downstream slice reads (root A, V3-#6).** A spool line is a JSON object with exactly two top-level members, and the DoD-1 fixture table asserts both:
   - **`hook`** — the hook payload, verbatim except for S4's redaction, under DoD 1's absent-not-invented rule. The non-base members downstream slices are permitted to read, each asserted present in at least one fixture: `tool_use_id`, `tool_name`, `tool_input`, `tool_output` (`preToolUse` / `postToolUse` / `postToolUseFailure` — ledger §A5.1:120,121,122); `is_interrupt`, `error_message`, `failure_type` (`postToolUseFailure` — :122); `file_path`, `content` (`beforeReadFile` — :127); `command`, `output`, `duration`, `sandbox` (`afterShellExecution` — :124); `mcp_server_name`, `result_json` (`afterMCPExecution` — :126); `tool_call_id`, `parent_conversation_id`, `subagent_id`, `subagent_type` (`subagentStart` — :131); `context_tokens`, `context_window_size`, `context_usage_percent` (`preCompact` — :136); `duration_ms`, `final_status` (`sessionEnd` — :118); **`status` (`stop` — :135)**, which S1b DoD 5's reader-side session-close heuristic reads alongside `sessionEnd` and which round 3's list omitted while the source-supply table already named it (`revision-log-round3.md` §1 row 25, V4-#15); `prompt` (`beforeSubmitPrompt` — :119); `text` (`afterAgentResponse` / `afterAgentThought` — :133,134). **No later slice may rely on a field outside this list without amending this DoD.**
   - **`received_at`** — an **RFC 3339 UTC timestamp stamped by this binary** when it finishes reading stdin. **No hook event carries a timestamp**: the ten base fields (ledger §A5.1:113) contain none, and no payload row at :117-137 carries one. This field is therefore **ours, not Cursor's**, and is namespaced *outside* `hook` so no reader can mistake it for a Cursor-supplied value (**D11**). It is the sole carrier of `TimingData.StartTime`/`.EndTime`, `ToolCallEntry.Timestamp` and `ActivationEntry.Timestamp` downstream, under D11's caveat — which S1b carries in the profile through SC's `Caveat` field, not in prose.
7. **CI runs every `tests/test_*.sh` by glob, once, so no later slice has to edit the workflow (V4-#7, C4-#1).** `.github/workflows/ci.yml:24-31` enumerates the four existing scripts by name (`test_skill.sh`, `test_walk.sh`, `test_f01.sh`, `test_f02.sh`); under that shape, `tests/test_hooks_install.sh` (S2), `tests/test_spike_activation.sh` (SP1), `tests/test_guardrails.sh` (S8a) and `tests/test_doc_labels.sh` (S8b's fallback) would each be committed, be green locally, and **never run**, while three of those slice files did not list `ci.yml` at all. This slice replaces the four named steps with one step — `for f in tests/test_*.sh; do echo "== $f"; "$f"; done` under `set -euo pipefail` — and **places it after the `actions/setup-go` step**, so a script may build the Go binaries it exercises. Two rules ride with it, stated here because this is where they become load-bearing: **(a)** every `tests/test_*.sh` is self-contained (it builds or skips what it needs) and exits non-zero on failure; **(b)** the glob runs in lexical order and no script may depend on another having run. The four existing scripts are unchanged and still run. This slice's own `tests/test_hook_latency.sh` is discovered by the same glob, and **the latency ceiling lives inside that script**, not in the workflow — so `ci.yml` is edited exactly once in the whole epic, by this slice.

## Test approach
`profiler/hooks_test.go` (new, this slice's own file): a table over **21** payload fixtures — one per event — asserting the exact spool line each produces, with `workspaceOpen` asserted as the four-field case rather than being forced through the blanket rule. That table is what actually proves R-CS-01 and R-CS-02 rather than asserting them in prose. It also asserts DoD 6: the two-member envelope, each listed non-base field surviving into `hook` on the event that supplies it, and `received_at` parsing as RFC 3339 UTC and being non-decreasing across a spool. Three failure-mode tests (malformed JSON, read-only spool dir, unknown event) each assert exit code 0 and empty stdout. One bounded-memory test feeds 10 MB on stdin and asserts exit 0 plus a capped line.
`tests/test_hook_latency.sh` (new): runs the binary N times over a representative payload, **records** p50/p95 as a **Repository fact** in the PR body, then fails if p95 exceeds **2× the measured p95** pinned as a constant at the top of the script. §G7 states the latency budget is unmeasured; the old DoD gated on an invented "<50 ms". This slice produces the number first and derives the gate from it.
**DoD 7 is proven, not asserted:** a temporary `tests/test_zz_glob_canary.sh` that exits non-zero is added, CI is observed red, and it is removed in the same PR — the red→green pattern S8a uses for its guardrails, applied to the wiring itself. State the observation in the PR body; commit no canary.
