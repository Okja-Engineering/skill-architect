## Goal
Join hook `conversation_id` to `POST /teams/filtered-usage-events` → `conversationId` and get genuinely billed per-request tokens — the cheapest real-token path for Cursor that does **not** require Enterprise OTel.

## Definition of done
With a Team admin key, a hook-sourced profile's `tokens` become `present` with `Source: "server_api"` and four-way splits (`inputTokens`, `outputTokens`, `cacheWriteTokens`, `cacheReadTokens`); without a key, the metric is `unknown` with an actionable reason and nothing else in the profile changes.

## Test approach
`profiler/admin_api_test.go` (new, this slice's own file): an `httptest` fake Admin API returning a canned `filtered-usage-events` body authored from the docs (§G6 — no key, no call and no real response body has ever been observed, so the fixture is Specification, not capture). Assert: the join matches on `conversationId`; a response containing other conversations contributes nothing; a missing key degrades to `unknown` and never fails hard (R-SA-13); a `server_api` result is in the `measured_billed` honesty class, so SC's rule refuses to difference it against an `estimated` baseline from S5.

## Next
**Do not dispatch until the user confirms a Team or Enterprise plan and an admin API key.**

Do **not** port cursorscope's poller (`src/cursor-api-poller.js:44,47`): it uses `GET /teams/{teamId}/daily-usage-data` with Bearer auth. The documented endpoint is `POST /teams/daily-usage-data` with Basic auth (API key as username) and no team path segment — and `daily-usage-data` has **no token fields at all**. Target `filtered-usage-events`.

**Rate-limit claim corrected at the spec gate.** Data is aggregated hourly and should be polled at most once per hour. The earlier "20 req/min per team, 30-day max range" for `filtered-usage-events` was transcribed by topic: the ledger (§A5.3) itself says only "20–250 req/min **by endpoint**" and pins the 30-day maximum to `daily-usage-data`/`audit-logs`. The reviewer's reading of the live docs gives **60 req/min** for this endpoint with no 30-day constraint. Treat the exact figure as **Specification, re-verify before building** — it is a one-page read and it changes the poller's backoff.
