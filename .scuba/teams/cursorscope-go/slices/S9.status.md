## Goal
Join hook `conversation_id` to `POST /teams/filtered-usage-events` → `conversationId` and get genuinely billed per-request tokens — the cheapest real-token path for Cursor that does **not** require Enterprise OTel.

## Definition of done
With a Team admin key, a hook-sourced profile's `tokens` become `present` with `Source: "server_api"` and the four-way splits mapped onto `TokenCounts` explicitly — `inputTokens→Input`, `outputTokens→Output`, `cacheReadTokens→CacheRead`, **`cacheWriteTokens→CacheCreation`** (the wire field is named "write", the contract field "creation"; the mapping is stated so it cannot drift). Field names are **Specification**, ledger §A5.3:180. Without a key, the metric is `unknown` with an actionable reason and nothing else in the profile changes.

## Test approach
`profiler/admin_api_test.go` (new, this slice's own file): an `httptest` fake Admin API returning a canned `filtered-usage-events` body authored from the docs (§G6 — no key, no call and no real response body has ever been observed, so the fixture is Specification, not capture). Assert: the join matches on `conversationId`; a response containing other conversations contributes nothing; a missing key degrades to `unknown` and never fails hard (R-SA-13); a `server_api` result is in the `measured_billed` honesty class, so SC's rule refuses to difference it against an `estimated` baseline from S5.
