## Goal
Produce every hook-derived token number under a label that names its honesty, so no reader — and no comparison — can mistake any of them for billed tokens. SC ships the *channels*; this slice ships the *producers*.

**The old dep on S3 was phantom** and is removed: token extraction needs no attribution, and parking S5 behind the slice most likely to collapse (S3, gated on SP1) was invented sequencing.

## Definition of done
Four sources, four labels — the old DoD said "three labels" while Fork (vi) listed three *representations* and left **MCP self-reported tokens with no label at all**, making it unexecutable:

| Source | Label | Honesty class (D3) | Carrier field |
|---|---|---|---|
| `chars/4` over hook payloads | `estimated` | estimated | `TokenCounts.Input`/`.Output` |
| `afterMCPExecution.result_json` → `usage` | `mcp_reported` | self_reported | `TokenCounts.Input`/`.Output` |
| `preCompact.context_tokens`, `context_window_size`, `context_usage_percent` | `hooks` | harness_reported | **`TokenCounts.ContextTokens` / `.ContextWindowSize` / `.ContextUsagePercent`** (added by SC) |
| Admin API / Enterprise OTel | `server_api` (**S9**) / `otel` (**S6**) | measured_billed / harness_reported | four-way splits on `TokenCounts` |

The third row is the round-2 repair: R-CS-13 and R-RL-18 assert `context_window_size` and `context_usage_percent`, `TokenCounts` (`types.go:80-86`) had no field for either, and this slice does not own `types.go`. SC adds the three fields; this slice fills them. The fourth row's slice mapping is also corrected — **S9 is the Admin API (`server_api`), S6 is Enterprise OTel (`otel`)**; the roadmap had them inverted.

No value produced by an `estimate*` function ever serializes with any other source. `docs/profiler-spec.md` records the structural undercount and that `preCompact` fires **only** on compaction (ledger §A5.1:141).

## Test approach
`profiler/tokens_test.go` (new, this slice's own file): one fixture per source asserting its exact `Source` string **and** the honesty class SC maps it to; a `preCompact` fixture asserting all three context fields are populated and that `ContextUsagePercent` is carried, never differenced; a fixture with **no** compaction asserting `preCompact` contributes nothing rather than zero; a negative test that `compare` **refuses** `estimated` vs `server_api` (SC's cross-class rule), so an estimate can never be silently differenced against a billed number — the failure `compareTokens` allows today, where the baseline's source is dropped entirely (`compare.go:115`).
