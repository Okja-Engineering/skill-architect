## Goal
Redaction runs before the spool write, not before export. Prompts hitting local disk is more sensitive than cursorscope's in-memory → OTLP path, so this is non-negotiable.

## Definition of done
Given a payload containing an email, a bearer token, an `sk-` key, and a 4 KB prompt, the spool file on disk contains none of them and records prompt length only; payloads are truncated at 8192 bytes.
