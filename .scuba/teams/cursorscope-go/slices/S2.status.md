## Goal
`hooks install` / `hooks uninstall` merge and unmerge `~/.cursor/hooks.json` without touching foreign hooks, with a timestamped backup and a clean uninstall; `doctor` reports state in one shot with no server.

The R-RL-17 spike **moved out of this slice to SP1**, ahead of S3: a spike that can void S3/S5/S7 must gate them, and it needs no code from us — the user can install a five-line hook by hand. That also unblocks this slice, which no longer waits on User Question 1.

## Definition of done
1. Against a fake `$HOME` seeded with a foreign hook, `install` then `uninstall` leaves `hooks.json` **byte-identical** to the original.
2. A timestamped backup file exists after `install`.
3. `install` run twice is idempotent — no duplicate entries, one backup per run.
4. `doctor` prints the resolved spool path, the installed hook entries and the binary version, exits 0 whether or not Cursor is present, and starts no server (R-CS-23 adapted).
5. **`--dry-run` and `--yes` exist and are tested (C3-#12).** R-CS-25's adapted verb set is `hooks install/uninstall`, `doctor`, **`--dry-run`**, **`--yes`** — round 2 claimed R-CS-25 here while neither flag appeared in the DoD or the tests, so the register asserted a requirement the slice did not carry. `install --dry-run` prints the exact merged `hooks.json` it *would* write and **writes nothing** — no file, no backup; `install --yes` skips the interactive confirmation, which is what makes the command usable from a script and from CI. Both apply to `uninstall` identically.

## Test approach
`tests/test_hooks_install.sh` (new): a fake `$HOME` fixture with a foreign hook; install → assert our entries present **and** the foreign entry unchanged; uninstall → `diff` against the original for byte-identity; a second install for idempotence; a backup-exists assertion. **For DoD 5:** `install --dry-run` against the fake `$HOME` asserts the printed body equals what a real `--yes` install then produces, and that the directory is byte-identical before and after the dry run (no file, no backup) — the boundary proven from both sides, as with S4's truncation.
**The merge itself is Go** (`skill-scope hooks install`) — it must be atomic, non-clobbering and backed up (**D7**). `jq` appears only in this test's byte-comparison, never as the merge engine; the roadmap's earlier "`jq` does the merge" line contradicted this file and is resolved. A `grep` assertion proves no `python3` appears anywhere in the path — cursorscope's merge shells out to it, and `AGENTS.md:6` rules it out.
