# Out of scope

Deliberate boundaries for the `skill-architect` plugin.

## What this plugin does not do

- **Automatically rewrite skills.** It reports and recommends; a human approves changes.
- **Drive the agent itself.** `profiler experiment` (F04) schedules and executes a paired run and `profiler compare` reports the differences, but the command that runs the agent and produces each profile is the caller's; the plugin never launches a model or spends tokens of its own.
- **Judge subjective quality.** It does not evaluate whether a skill's advice is good, only whether its structure, triggers, scripts, and context management follow the spec and best practices.
- **Guarantee security.** It runs structural checks and points to common risks, but it is not a substitute for a full security audit.
- **Manage skill marketplaces or catalogs.** It evaluates single skills or local directories, not distribution, signing, or versioning at scale.

## What it does do

- Provide deterministic checks for the most common failure modes of Agent Skills.
- Score skills on a clear 0–2 matrix grounded in the spec, Anthropic best practices, ICM, and industry evaluation research.
- Surface concrete, ordered fixes.
